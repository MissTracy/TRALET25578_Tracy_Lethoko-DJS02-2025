# Podcast Preview Web Component

## Overview

This project is a reusable Podcast Preview Web Component built using native JavaScript, HTML, and CSS.

The component displays podcast information such as:

- Cover image
- Podcast title
- Genres
- Number of seasons
- Last updated date

The project uses the Web Components API with Shadow DOM encapsulation to create a modular and reusable custom HTML element.

---

## Features

- Reusable custom HTML element
- Encapsulated styles using Shadow DOM
- Stateless component design
- Responsive podcast preview layout
- Custom interaction events
- Native JavaScript implementation (no frameworks)

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Web Components API
- Shadow DOM
